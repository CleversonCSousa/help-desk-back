# HelpDesk

O HelpDesk é um sistema de gerenciamento de chamados desenvolvido com o intuito de otimizar o fluxo de suporte técnico.

O front-end do projeto se encontra com um guia de configuração no seguinte repositório: [HelpDesk Front-end](https://github.com/CleversonCSousa/help-desk-front)

## Requisitos para rodar o Projeto
Para rodar o back-end do projeto, é necessário que você tenha o Docker instalado na sua máquina.
